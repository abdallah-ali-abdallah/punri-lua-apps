# PUNRI Lua application provenance

This repository contains the Lua applications and App Store catalog extracted
from [PUNRI](https://github.com/abdallah-ali-abdallah/punri). PUNRI builds on
[CrossSmudge](https://github.com/Mumfee/CrossSmudge),
[CrossInk](https://github.com/uxjulia/crossink), and
[CrossPoint Reader](https://github.com/crosspoint-reader/crosspoint-reader).

The original MIT copyright and permission notice is preserved in `LICENSE`.
Per-application authors, source comments, assets and any asset-specific notices
are retained. The repository license does not override third-party asset
licenses.

Moving the packages does not rename released Lua API aliases or device data
paths. Installed applications remain in `/.crosssmudge/applications/`, with
`/.smudge/applications/` retained as a compatibility path.
