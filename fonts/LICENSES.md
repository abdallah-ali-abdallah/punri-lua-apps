# Font license notices

Every `.cpfont` asset in this directory is derived only from an open-source
font. It remains available under the source font's license, separately from
the repository's MIT license.

## Midad-compatible catalog

The 34 shared families are byte-for-byte packages from the stable
[CrossPoint Fonts `sd-fonts-m1-b4` release](https://github.com/crosspoint-reader/crosspoint-fonts/releases/tag/sd-fonts-m1-b4).
Midad's release workflow builds its catalog from the same CrossPoint font
configuration. That release's [license notice](https://github.com/crosspoint-reader/crosspoint-fonts#license)
states that it contains converted open-source fonts under their original
licenses, primarily SIL Open Font License 1.1 and Apache License 2.0.

`metadata.yaml` and `fonts.json` retain each family's upstream source URL,
release URL, description, supported scripts, file sizes, and SHA-256 digests.
Do not add a font unless its upstream license permits redistribution and is
recorded there.

`NotoSansArabic` remains a separately generated family from the
[Noto Arabic project](https://github.com/notofonts/arabic), under SIL Open
Font License 1.1. The full OFL text is in [OFL-1.1.txt](OFL-1.1.txt).
